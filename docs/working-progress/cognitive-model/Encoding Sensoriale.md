# Descrizione:
- L'interfaccia tra l'ambiente esterno e il modello avviene tramite una codifica deterministica dei segnali nella fase non deterministica del modello.

# Esempi:
- **Udito:** un suono viene convertito in una sequenza manipolabile; variazioni minime di frequenza producono codici molto simili
- **Vista:** un'immagine viene trasformata in valori; sfumature di colore o forma generano codici vicini
- **Linguaggio:** una parola viene codificata in una seguenza; parole scritte in modo simile (es.: 'ciao' e 'cia') producono codici itemsimili
- **Tatto:** una sensazione viene tradotta in valori; leggere differenze di pressione mantengono codici correlati
